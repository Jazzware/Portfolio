# Portafolio de Iván López Villegas

Sitio personal de Iván López Villegas, ingeniero de software: **https://jazzware.dev**

Reúne su experiencia, las herramientas con las que trabaja y
[PaleoSharp](https://paleosharp.jazzware.dev), un juego para aprender C# en el navegador.
Está en español e inglés.

El diseño sigue la convención de la ilustración arqueológica: las figuras se dibujan como piezas de
cerámica en corte, y la trayectoria profesional aparece como una vasija de rollos, un rollo por puesto.

Hecho con [Astro](https://astro.build) y TypeScript.

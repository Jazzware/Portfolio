# CV

Fuente del CV de Iván López Villegas, en español e inglés, una hoja.

- `cv_final_*.html`: versión de pantalla (con modo oscuro).
- `cv_print_*.html`: versión de impresión; de aquí salen los PDF.
- `render_pdf.js`: genera los PDF en `public/cv/` (el sitio los sirve en `/cv/`).

Para regenerar los PDF, desde la raíz del repo:

```
npm run cv
```

Este repo es público, así que el CV no incluye teléfono. La versión con teléfono se mantiene fuera del repo.
